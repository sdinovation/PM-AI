P0 修复 "Assignment to constant variable" JS错误（13处）
问题：const timeRange 在后续代码中被重新赋值（timeRange = ctx.timeRange），导致13次JS运行时错误，影响多个数据集的测试。
原因：parseTimeRange() 返回值声明为 const，但在多轮对话上下文继承时需要更新。
修复：将 const timeRange 改为 let timeRange。
- const timeRange = parseTimeRange(q, dateField, rows); + // Fix: 改为 let 避免后续重新赋值时错误 + let timeRange = parseTimeRange(q, dateField, rows);

P0 修复 "贵州茅台和五粮液的收盘价对比" 返回空响应
问题：对比查询返回空响应（SQL空、文本空、图表空），意图正确识别为 comparison 但无结果输出。
原因：isCompareQuestion() 对所有含"对比"的问题返回 'value'，导致 parseDimension() 中 cmpType === 'value' 分支直接 return null，维度为空使后续对比过滤逻辑无法执行。
修复：在 parseDimension() 中，当对比类型为 'value' 且问题含"A和B"模式时，优先返回含"名称"的维度字段。
if (cmpType === 'value') { + // Fix: 实体对比（"A和B...对比"）不应返回null + if (/(.+和.+)/.test(q)) { + const nameField = dimensionFields.find(f => + /名称|姓名|名字/.test(f) && !/ID|id|号/.test(f)); + if (nameField) return nameField; + } return null; }

P1 修复 "股票代码" 被误判为数值指标（SUM(股票代码)）
问题：股票代码（值如 600519）被 inferFieldType() 识别为 int 类型，导致多指标查询SQL中出现 SUM(股票代码)。
原因：inferFieldType() 仅检查字段名是否含"日期/金额/率"等关键词，对全数字值的标识符字段（如股票代码）无特殊处理。
修复：(1) 添加"代码/编号/ID"关键词检测；(2) 添加高唯一率整数列检测（唯一值比例>80%且字段名不含指标关键词时判定为text）。

'int' : 'float'; } }
