欢迎使用数分精灵 v1.0.1 ✨

我是你的 AI 数据分析助手。上传 CSV/Excel 文件，用中文描述需求，自动生成分析结果。

📂 数据上传与切换
支持 CSV / Excel，单文件 ≤ 50MB。可添加多个数据源（最多 3 个），切换数据源。
入口：空态页拖拽区 / 文件栏「添加表格数据」/ 文件名点击展开下拉

💬 自然语言分析
自动识别维度/指标/时间/排序/条数限制，生成图表并附 SQL 语句。
入口：底部输入框直接提问，支持 Enter 发送

🤖 AI 增强模式
配置 API Key（Anthropic/OpenAI/DeepSeek 等），LLM 增强解读 + 报告智能填充。
入口：右上角用户头像 → API Key 配置

📊 数据画像
字段类型统计、缺失率、类型分布图表，独立滚轮区域。
入口：文件栏「数据画像」按钮

📝 SQL 展示与数据表
自动生成 SQL 语句，查询结果表格展示，支持展开全部行。
入口：AI 回复气泡中折叠的 SQL 和表格块

📄 数分报告
一键生成八章结构化报告，预览/编辑/导出 HTML/Word/PDF。
入口：文件栏「下载报告」/ 说"导出报告"自动生成

🔍 对话管理
左侧历史对话列表，时间分组，搜索/重命名/展开收起/新建对话。
入口：左侧侧栏（点击左上角展开）

💡 输入建议
输入时自动推荐分析问题，基于数据字段智能生成。
入口：底部输入框，打字自动弹建议列表

🌓 主题切换
浅色/深色模式，图表和样式实时跟随。
入口：右上角用户头像 → 主题设置

👍 反馈系统
对话和报告点赞/点踩，细化原因反馈。
入口：AI 回复底部 👍👎 / 报告预览底部反馈区 / 用户头像 → 意见反馈
